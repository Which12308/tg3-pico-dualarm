# PICO 位姿跟随、Revo 2 触觉抓瓶与示范采集

## 操作

1. 用 USB 将 PICO 接到电脑，用网线将电脑接到机器人。双击 `启动有线遥操作.cmd`，选择 `hardware`、`xarm`、`pose`。已有同版本头显 App 可继续使用。
2. 从「加载灵巧手标定」载入本机右手配置。要让转动围绕实际抓握点发生，在「工具标定」保存控制器到操作点、机器人 TCP 到掌心抓握点的实测变换。使用模型 TCP 时，旋转围绕模型末端。
3. 头显选 USB 并完成配对。部署后，由现场操作者启用运动。握住右侧键，手柄平移和转动同时映射到右手掌的位置和朝向。松键保持，重握以当前位置为起点。
4. 对准瓶身后逐渐扣右扳机。手指为拇指对掌留出空间，拇指就位后其余手指沿标定方向合拢。承力触点建立后，驱动进入电流持握，电流按各指法向触觉反馈微调。松扳机后继续持握。右 **B** 优先释放，四指打开后拇指归位。

## 双臂回初始姿态

启用真机运动并完成接管后，软件保存当次双臂实测关节姿态。放稳物体、松开全部手柄按键并确认双臂回位路径有空间，再点「双臂回初始姿态」。双臂按平滑关节轨迹返回记录的姿态，界面收到实测到位反馈后显示「双臂已到初始姿态」。回位期间沿用原来的站立和手指控制状态。

回位时按下手柄按键或中断跟踪会中止回位并保持最后下发的目标。松键后可以继续用握持键跟随，也可以再点一次按钮。可随时点「停用并停止本项目」。重新启用后记录新的初始姿态。

电流持握由触觉接触触发。合到位置终点且无触觉接触时，保持最后的位置指令。触觉数据中断时停止电流调节，已发送的指令由厂家驱动处理。停用和交还控制仍使用基线流程。

## 本机标定

沿用原来的手部 JSON，其中 `hands.right`、`hand_raw_rate.right`、`hand_raw_lead.right` 仍来自原实测开合配置。增加顶层 `right_tactile` 对象。配置只带原有字段时，操作台仍使用原位置抓握。

| `right_tactile` 字段 | 填写内容 |
| --- | --- |
| `current_mode` | 本机 ROS 驱动 `SetMotorMulti.mode` 对应的有符号电流控制枚举。从已安装驱动的说明或源码确认。 |
| `thumb_position`、`position_tolerance` | 拇指对掌的实测原始位置，及开口／拇指到位姿态的原始位置容差。 |
| `support_fingers` | 抓同款瓶时能承力的指垫编号。五指编号从 0 开始，须包含拇指及至少两个对侧触点。 |
| `contact_threshold`、`target_force`、`force_deadband` | 五指接触阈值、目标法向压力、调节死区。单位为本机 `TouchStatus` 原始读数。 |
| `current_min`、`current_max`、`current_step` | 五指最小、最大持握电流及每次调节量。填写经过本机标定的驱动单位。 |
| `closing_sign`、`opposition_current` | 五指朝合拢方向的电流符号，以及拇指对掌电机的有符号维持电流。 |
| `evidence` | 驱动版本、枚举出处、瓶型和标定依据。 |

五指字段按拇指、食指、中指、无名指、小指排列。底层六通道第二项是拇指对掌轴。现场日志确认 `/right_hand/touch_status` 发布 `brainco_hand_msgs/msg/TouchStatus`，以及 `/right_hand/set_motor_multi` 接收 `brainco_hand_msgs/msg/SetMotorMulti`。公开示例给出 SDK 接口，机器人私有 ROS 驱动的电流枚举和实测电流数据待补。包中没有填充猜测的枚举、力值或瓶型标定。

官方方案参考 BrainCo Revo 2 示例中的位置趋近、触觉判定和动态电流调节。这里用指定瓶型的逐指法向压力闭环。 [BrainCo 官方触觉抓取示例](https://www.brainco-hz.com/docs/revolimb-hand/revo2/tactile_grasp.html)

## 采集一条示范

1. 在操作台选择电脑或 U 盘上的目录。「选择数据／相机」中选需要的机器人反馈、手指控制、`/right_hand/touch_status` 及相机。
2. 点「开始录制」，完成一轮抓取、提起、放回及释放，点「停止录制」。每次开始创建一个新目录。录制通道独立。
3. 停止后选成功或失败并点「保存示范结果」。每条目录包含 `session.json`、`outcome.json`、分片 MCAP 和 JSONL。JSONL 保存控制器帧、掌心和 TCP 的目标及实测计算位姿、关节指令与反馈、触觉持握状态和周期耗时。

真机验收可用同一只空瓶，连续完成五次完整抓放。提起约 5 cm，松扳机保持 5 秒，再放稳按 B。
