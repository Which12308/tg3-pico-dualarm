# 天工 3.0 × PICO 双臂遥操作与触觉抓取

整合版基于现场已报告流畅跟手的 `dd139a9`。侧握键接管手掌位置和朝向，
右扳机控制抓握，右 B 张手。手掌完整位姿、右手触觉持握和手动示范录制
使用同一个操作台。操作及触觉标定字段见 [触觉抓瓶与示范采集](docs/tactile_bottle_grasp.md)。

下方是基线的历史记录。整合版的验证结果随安装包附带。

2026-11-22 本地修改：原控制链默认由外部模块负责运动限制与自动停机，标记为
`safety.LIMITS_MANAGED_EXTERNALLY = True`。继续使用原有相对映射、原生 Placo、
真实反馈、厂家适配和原启动入口；没有独立 `simulate` 入口或 NumPy 替代求解器。

本仓库不再对运行目标执行关节/速度/加速度/末端速度限幅、相对工作空间/手柄跳变检查、
输入/反馈/命令年龄及命令看门狗停机，也不因 IK 超时、越限或残差停滞自动停用。
XARM 提交和原厂输出转发不再重复限幅，接管时不再把厂家速度参数压到本仓库的候选上限；
原厂自身已有参数、模式及固件行为仍由原厂实现决定。手部保留原标定和按钮语义，
移除本仓库附加的闭合速率及反馈走廊限制。

手动停用、退出及物理急停仍走原停止/释放流程；手动停用后迟到的 IK 结果被丢弃。
维度、有限数值、消息编码、网络认证、厂家控制权与服务 ACK 等接口要求仍保留。
无法计算或通信失败会报告错误，不生成虚假的成功结果。外部模块的实际接线和部署不在本次改动中。

`python scripts/run_tests.py` 分别报告历史本地保护规则的兼容回归与当前默认无约束链测试。
前者在测试进程内显式恢复旧规则，后者验证原映射、控制器、厂家目标和实际输出转发不再限幅，
并验证手动停止。测试使用明确标记的硬件替身，不等于原生 Placo 或真机验收。

以下为修改前的快照说明，其中本仓库限幅行为以上述本地修改为准。

这是 2026-11-18 最后上机版本（候选 08）的审阅快照。已去除操作台预填的现场地址和测试中引用的该地址，省略了本机记录、机器人模型、安装二进制和自动 CI。复现运行需要项目原始资产及相应原生环境。

本次真机通过了输入接收、厂家接管和停用恢复。右握持键触发了跟随，原生求解已运行，但右臂只短暂响应，随后因 `xarm_feedback_lead_exceeded` 退出。持续跟随和抓取尚未通过。
